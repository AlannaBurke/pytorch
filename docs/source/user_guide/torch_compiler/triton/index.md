# Triton

[Triton](https://triton-lang.org/) is an open-source, Python-based programming
language and compiler for writing highly efficient custom GPU kernels. It is a
key building block in the PyTorch compiler stack: TorchInductor uses Triton as
its default code generator for NVIDIA, AMD, and Intel GPUs.

This section provides conceptual documentation on Triton and its role in the
PyTorch ecosystem. For hands-on tutorials, see the
[Triton tutorials](https://pytorch.org/tutorials/) on the PyTorch Tutorials
site.
